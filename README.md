# 🚀 DSA Visualizer

An interactive web application to visualize Data Structures and Algorithms in real-time.

---

## 📌 Features

* 📦 Stack Visualizer (LIFO)
* 🔁 Queue Visualizer (FIFO)
* 📊 Sorting Algorithms

  * Bubble Sort
  * Selection Sort
  * Merge Sort (with Call Stack Visualization)
* 🔍 Search Algorithms

  * Linear Search
  * Binary Search (with pointer visualization)
* 🎨 Modern UI with card-based navigation
* 🌙 Smooth animations and transitions

---

## 🧠 Concepts Covered

* Stack & Queue
* Sorting Algorithms
* Recursion & Call Stack
* Time Complexity Visualization
* Binary Search Optimization
