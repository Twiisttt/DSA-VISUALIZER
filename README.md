# 🚀 DSA Visualizer

An interactive web-based platform to learn **Data Structures & Algorithms visually**.

This project helps students understand DSA concepts through animations, visualization, quizzes, and user progress tracking.

---

# 🌐 Live Demo

🔗 [https://twiisttt.github.io/DSA-VISUALIZER/](https://twiisttt.github.io/DSA-VISUALIZER/)

---

# 📌 Features

## ✅ Data Structure Visualizations

* Stack Visualization (Push / Pop)
* Queue Visualization (Enqueue / Dequeue)
* Searching Algorithms

  * Linear Search
  * Binary Search
* Sorting Algorithms

  * Bubble Sort
  * Selection Sort
  * Merge Sort

# 🧩 Concepts Used

## DOM Manipulation

Used JavaScript DOM methods to dynamically update visual elements.

Examples:

* Creating bars during sorting
* Updating stack/queue elements
* Displaying search highlights

---

## Asynchronous Programming

Used:

* async / await
* sleep() function

This helps animate algorithms step-by-step.

---

## Recursion & Call Stack

Merge Sort visualization includes recursion stack tracking.

Used to visually explain:

* Recursive calls
* Function stack behavior
* Divide and conquer approach

---

## Modular Architecture

Project is divided into multiple files:

* HTML pages
* CSS styling
* Separate JavaScript modules

This improves maintainability and scalability.
